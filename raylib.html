Why I use it

I like being close to the game loop.

Windowing, input, drawing, audio, and math are all there. I can write the loop myself, try an idea, and see the result without much setup.

My language bindings

Five ways in.

I started with rayscal, then tried Oberon, Modula, F*, and Mojo. Each project explores how to use raylib from a different language while keeping the native API accessible.

rayscal

Scala-owned values, explicit resource lifetimes, and C shims for native calls that need them.

Window.withWindow(800, 450, "hello rayscal"):
  Window.setTargetFps(60)
  while !Window.shouldClose do
    Drawing.frame:
      Drawing.clear(Colors.RAYWHITE)
      Drawing.text("Hello from Scala!", 220, 200, 28)
